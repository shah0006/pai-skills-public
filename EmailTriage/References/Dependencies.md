## Dependencies

- AppleMail (`Tools/apple-mail.sh` v3.0+) — iCloud transport
- GoogleWorkspaceCLI + `gws` — Gmail transport (sole writer for account `g`)
- Bun runtime (`bun:sqlite`)
- Optional: Anthropic API key in `web/.env.local` for AI features
- Optional: Ollama (`http://localhost:11434`) as the AI fallback
